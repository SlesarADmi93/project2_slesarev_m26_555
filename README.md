# project2_Slesarev_M26_555 Primitive DB

Консольное приложение, имитирующее работу с базой данных. Проект позволяет создавать и удалять таблицы, добавлять, просматривать, изменять и удалять записи. Метаданные и данные сохраняются в JSON-файлах.

## Предварительные требования

Для работы с проектом через `Makefile` (рекомендуемый способ) необходимо наличие утилиты `make`.

- **Linux / macOS**: `make` обычно предустановлен.
- **Windows**: 
  - Рекомендуется установить [Git Bash](https://git-scm.com/downloads) и использовать его терминал.
  - Либо установить `make` через пакетный менеджер [Scoop](https://scoop.sh/): `scoop install make`.
  - Либо использовать [Chocolatey](https://chocolatey.org/): `choco install make`.

## Возможности

- управление таблицами;
- операции CRUD: `INSERT`, `SELECT`, `UPDATE`, `DELETE`;
- автоматическая генерация уникального `ID`;
- поддержка типов `int`, `str`, `bool`;
- фильтрация записей по условиям `WHERE`;
- вывод результатов в виде таблиц с помощью PrettyTable;
- сохранение метаданных и записей между запусками программы.

## Требования

- Python 3.12 или новее;
- [uv](https://docs.astral.sh/uv/).
- **Make** — утилита для автоматизации сборки и запуска.

## Альтернатива без Make - установка и запуск

Клонируйте репозиторий и перейдите в каталог проекта:

```bash
git clone <URL-репозитория>
cd <каталог-проекта>
```

Установите зависимости:

```bash
uv sync
```

Запустите программу из каталога проекта:

```bash
uv run database
```

После установки пакета в соответствующее окружение команду `database` можно запускать напрямую:

```bash
database
```

Введите `help` в запущенной программе, чтобы увидеть справку.

| Команда | Назначение |
|---|---|
| `create_table <имя> <столбец:тип> ...` | Создать таблицу с указанными столбцами |
| `drop_table <имя>` | Удалить таблицу из метаданных |
| `list_tables` | показать все таблицы |
| `insert into <имя> values (<значение1>, <значение2>, ...)` | Добавить запись |
| `select from <имя>` | Вывести все записи таблицы |
| `select from <имя> where <столбец> = <значение>` | Вывести записи, соответствующие условию |
| `update <имя> set <столбец> = <значение> where <столбец> = <значение>` | Изменить поля найденных записей |
| `delete from <имя> where <столбец> = <значение>` | Удалить записи, соответствующие условию |
| `info <имя>` | Показать структуру таблицы и количество записей |
| `help` | Показать справку |
| `exit` | Завершить работу программы |

### Правила ввода

- Поддерживаемые типы столбцов: `int`, `str`, `bool`.
- Столбец `ID:int` добавляется автоматически при создании таблицы. Передавать значение `ID` в команде `insert` не нужно.
- Все поля обязательны при добавлении записи.
- Строковые значения необходимо заключать в одинарные или двойные кавычки.
- Логические значения задаются как `true` или `false`.
- Несколько условий в `WHERE` или несколько полей в `SET` разделяются запятыми.

## Пример работы

```text
>>> Введите команду: create table users name:str age:int is_active:bool
Таблица "users" успешно создана.

>>> Введите команду: insert into users values ("Sergei", 28, true)
Запись с ID=1 успешно добавлена в таблицу "users".

>>> Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |    True   |
+----+--------+-----+-----------+

>>> Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.

>>> Введите команду: select from users where age = 29
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 29  |    True   |
+----+--------+-----+-----------+

>>> Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".

>>> Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0

>>> Введите команду: exit
Работа базы данных завершена.
```

## Хранение данных

- `db_meta.json` — метаданные: имена таблиц и описание их столбцов;
- `data/<имя_таблицы>.json` — записи соответствующей таблицы, например `data/users.json`.

Метаданные и записи сохраняются в JSON, поэтому данные остаются доступны после перезапуска программы.
